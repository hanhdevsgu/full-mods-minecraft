# 🤖 Bot Dọn Phễu (Minecraft 1.12.2)

Bot tự động dọn phễu, dọn rương, khóa góc nhìn FreeLook chuẩn xác, tự động nhận diện sảnh lobby mở GUI chọn server bằng la bàn (compass), click rìu kim cương, và tự động `/home` về Nhà Rương an toàn khi vào lại game.

---

### 📥 Tải Về Trực Tiếp

👉 **[TẢI VỀ BOT DỌN PHỄU (botdonpheu.zip)](https://github.com/hanhdevsgu/full-mods-minecraft/releases/download/botdonpheu-latest/botdonpheu.zip)** *(Click để tải ngay)*

> *Gói tải về gồm đúng 3 file: `bot_ws.py`, `server.js`, `worker.js` (không có file rác).*

---

### 📦 Danh sách file:
- `bot_ws.py` — Giao diện GUI điều khiển & quản lý tài khoản
- `server.js` — WebSocket server điều phối tiến trình
- `worker.js` — Core Mineflayer xử lý dọn rương, FreeLook & auto reconnect
