# Quick Craft 1.12.2

Mod tự động chế tạo vật phẩm tốc độ cao (Quick Crafting) cho Minecraft Forge 1.12.2.

---

## 📖 Hướng Dẫn Sử Dụng (Usage)

### 1. Cách cài đặt:
1. Tải file mod `.jar` ở phần **Download** ở dưới cùng trang này.
2. Nhấn tổ hợp phím `Windows + R`, nhập `%appdata%\.minecraft\mods` rồi nhấn **Enter**.
3. Sao chép file **`quickcraft-1.0.jar`** vào thư mục `mods`.
4. Khởi động Minecraft với phiên bản **Forge 1.12.2**.

---

### 2. Cách hoạt động trong game:
- **Phím tắt `V`:** Nhấn phím **V** để mở giao diện cài đặt Quick Craft. Tại đây bạn có thể nhập ID vật phẩm muốn chế tạo tự động (mặc định là `42` - Khối Sắt / Iron Block) và bật/tắt mod.
- **Tự động chế tạo:** Khi bạn mở Bàn chế tạo (Crafting Table) hoặc Rương/Shulker Box, mod sẽ tự động rút nguyên liệu, ghép đồ thành phẩm trong tích tắc và tự động đóng menu khi chế tạo xong.
