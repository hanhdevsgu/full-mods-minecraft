# Auto Hotbar Refill 1.12.2

Mod tự động bổ sung khối và vật phẩm lên thanh Hotbar cho Minecraft Forge 1.12.2.

---

## 📖 Hướng Dẫn Sử Dụng (Usage)

### 1. Cách cài đặt:
1. Tải file mod `.jar` ở phần **Download** ở dưới cùng trang này.
2. Nhấn tổ hợp phím `Windows + R`, nhập `%appdata%\.minecraft\mods` rồi nhấn **Enter**.
3. Sao chép file **`AutoHotbarRefill-1.12.2-1.0.jar`** vào thư mục `mods`.
4. Khởi động Minecraft với phiên bản **Forge 1.12.2**.

---

### 2. Cách hoạt động trong game:
- **Phím tắt `K`:** Nhấn phím **K** để BẬT hoặc TẮT tính năng tự động lấy đồ.
- **Tự động bù đồ:** Khi bạn sử dụng hết một khối hoặc vật phẩm trên thanh hotbar (ví dụ khi đang xây dựng), mod sẽ tự động tìm vật phẩm cùng loại trong túi đồ (inventory) và chuyển lên đúng ô hotbar đó để bạn tiếp tục sử dụng mà không cần mở rương đồ.
