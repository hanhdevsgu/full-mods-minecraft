# 🌊 Impact Client - Bản Tự Xây Sàn Nước (Minecraft 1.12.2)

Bản mod Impact Client 1.12.2 tích hợp Baritone tự động đặt block và xây sàn trên mặt nước cực nhanh, không lo block ảo hay rơi xuống nước.

## ⚙️ Hướng dẫn cài đặt

1. Nhấp vào link tải file **`impact-xay-san-nuoc.jar`** ở trên.
2. Nhấn tổ hợp phím `Windows + R`, nhập `%appdata%\.minecraft\mods` và nhấn **Enter**.
3. Copy file `impact-xay-san-nuoc.jar` vừa tải vào thư mục `mods`.
4. Mở Minecraft Launcher (Forge 1.12.2 hoặc ForgeOptiFine 1.12.2) và vào game.

---

## 🛠️ Tính năng chính

- **Xây sàn nước tự động**: Hỗ trợ đặt block trên mặt nước không bị rơi.
- **Tích hợp RealMouseHelper**: Tự động reset bộ đếm chuột phải Minecraft, giữ nhịp đặt block ổn định không ghost block.
- **Tương thích cao**: Hoạt động mượt mà với Forge 1.12.2 và OptiFine.
