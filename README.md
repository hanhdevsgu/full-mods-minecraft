# 🌾 Bot Farm (Minecraft 1.12.2)

Bot tự động farm quái, farm cây trồng, tự động nhặt đồ và duy trì hoạt động trong server Minecraft 1.12.2.

### 📦 Danh sách file:
- `bot_ws.py` — Giao diện GUI điều khiển & quản lý tài khoản
- `server.js` — WebSocket server điều phối tiến trình
- `worker.js` — Core Mineflayer xử lý logic bot farm
