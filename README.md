# 🌾 Bot Farm / Auto Farm (Minecraft 1.12.2)

Bot tự động farm, auto sell, fast use, khóa góc nhìn FreeLook, tự động mở GUI chọn server bằng la bàn (compass), click rìu kim cương, và tự kill `node.exe` khi kẹt session để khởi động lại sạch sẽ.

---

### 📥 Tải Về Trực Tiếp

👉 **[TẢI VỀ BOT FARM (botfarm.zip)](https://github.com/hanhdevsgu/full-mods-minecraft/releases/download/botfarm-latest/botfarm.zip)** *(Click để tải ngay)*

> *Gói tải về gồm đúng 3 file: `bot_ws.py`, `server.js`, `worker.js` (không có file rác).*

---

### 📦 Danh sách file:
- `bot_ws.py` — Giao diện GUI điều khiển & quản lý tài khoản
- `server.js` — WebSocket server điều phối tiến trình
- `worker.js` — Core Mineflayer xử lý auto farm, sell, fast-use & auto reconnect
