# Baritone 1.12.2

A Minecraft pathfinder and automation mod for Minecraft Forge 1.12.2.

---

## 📖 Hướng Dẫn Sử Dụng (Usage)

### 1. Cách cài đặt:
1. Tải file mod `.jar` ở phần **Download** ở dưới cùng trang này.
2. Nhấn tổ hợp phím `Windows + R`, nhập `%appdata%\.minecraft\mods` rồi nhấn **Enter**.
3. Sao chép file **`baritone-standalone-forge-1.2.19.jar`** vào thư mục `mods`.
4. Mở Minecraft và khởi chạy với phiên bản **Forge 1.12.2**.

---

### 2. Các lệnh điều khiển trong game:

Nhập trực tiếp các lệnh sau vào khung chat của game:

| Lệnh | Công dụng |
| :--- | :--- |
| `#sel 1` | Đặt điểm chọn thứ 1 tại khối đang nhìn hoặc vị trí chân đứng |
| `#sel 2` | Đặt điểm chọn thứ 2 để tạo vùng chọn giữa 2 điểm |
| `#sel ca` | Tự động đào dọn sạch toàn bộ vùng chọn giữa điểm 1 và điểm 2 |
| `#sel clear` | Hủy bỏ vùng chọn hiện tại |
| `#mine <tên_khối>` | Tự động tìm đường và đào loại khối chỉ định (ví dụ: `#mine diamond_ore`) |
| `#goto <x> <z>` | Tự động tìm đường đi đến tọa độ X Z |
| `#goto <x> <y> <z>` | Tự động tìm đường đi đến tọa độ X Y Z |
| `#follow player <tên_người_chơi>` | Tự động đi theo một người chơi |
| `#stop` | Dừng ngay lập tức mọi hoạt động của bot |
| `#resume` | Tiếp tục hành động trước đó |
