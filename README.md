# MacroRecorder - Mod Tự Động Mua Cát (Minecraft 1.12.2)

Mod tự động mua cát, chuyển vào kho `/pv` và về nhà cất vào rương cho Minecraft 1.12.2 Forge.

---

## 🚀 Tính Năng Chính
1. **Auto Mua Cát**: Tự động tương tác NPC Monster/Dân làng tại Shop, mua full túi và cất vào kho `/pv`.
2. **Auto Về Nhà Cất Đồ**: Tự `/home`, rút đồ từ các kho `/pv` và cất vào hệ thống rương tại nhà. Rương đầy tự động `#goto` sang rương tiếp theo.
3. **Tích Hợp QuizPeek Sẵn Trong Mod**:
   - Tự động sinh file `quizpeek_answers.json` với đầy đủ 31 bộ câu hỏi khi lần đầu cài mod.
   - Timing mặc định chuẩn `1.5s` trong `quizpeek_timing.json`.
   - Cấu hình F8 (`macrorecorder.json`) được tạo sẵn chuẩn cấu hình hoạt động ngay mà không cần copy bất kỳ file JSON nào qua.

---

## 🎮 Phím Tắt Điều Khiển
- **F8**: Mở GUI cấu hình Macro.
- **F4**: Bắt đầu chu trình tự động (Mua tại shop / Bán / Về nhà cất rương lặp vô hạn).
- **F10**: Dừng Macro ngay lập tức.
- **U**: Mở GUI quản lý thứ tự nhiều nick chạy song song.
- **K**: Bật/tắt chế độ tự trả lời QuizPeek.
- **X**: Mở GUI chỉnh độ trễ trả lời QuizPeek (mặc định 1.5s).
